# Demo Guide

## Planned Demo Flow
1. Register a demo student.
2. Add subjects, assignments, exams, and fixed class events.
3. Show calendar month/week/day views.
4. Create an intentional conflict.
5. Run conflict detection and compare multiple recommendations.
6. Generate study blocks around deadlines.
7. Ask the assistant a natural-language scheduling question.
8. Show reminders, analytics, and integration sync status/mock mode.

## Current Demo Status
Database foundation is ready; user-facing flows are pending.
